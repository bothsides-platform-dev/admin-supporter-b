# 견적 조건 v2 호환 읽기

본 서비스 bidit의 `quote_terms._v=2`를 조건의 기준으로 읽는다. 가입비·보증보험·수수료는 미입력/금액/협의 필요/해당 없음을 구분하며 숫자 열의 NULL을 0으로 변환하지 않는다. 기존 `_v=1` 숫자는 그대로 보존한다. 손상된 v2·알 수 없는 판본은 미입력으로 표시하고 오래된 숫자 투영으로 대체하지 않는다.

`lib/quote/terms.ts`는 bidit의 같은 경로와 공유하는 문서 계약이다. 어휘·검증·표시를 바꿀 때 양쪽을 맞춘다. 보증보험은 금액(원)만 표시하고 기간·보험료·유불리를 추정하지 않는다. 개인 `bid_drafts`는 관리자 견적 조회에 포함하지 않는다.

배포 순서: bidit의 `20261101-pg-workspace-v2.sql` 적용 → 이 콘솔의 호환 읽기 배포 → bidit 배포 → 양쪽 표시 확인. bidit은 쓰기 플래그 없이 배포 즉시 v2 견적을 저장하므로(supporter-b#828) 이 콘솔을 먼저 배포한다. v2 쓰기 시작 후 이전 읽기 코드로 롤백하지 않는다. 본 콘솔에는 쓰기 플래그나 초안 API를 추가하지 않는다.
