# 업종 목록과 기본 추천 PG

`/pg-recommendations`의 편집 권한은 기존 `recommendation.edit`를 사용한다.

## 운영 순서

1. 구매사 저장소의 `scripts/sql/20260924-pg-matching-defaults.sql`을 두 앱 배포 전에 적용한다. DB 스키마의 소유권은 구매사 저장소에 있다.
2. 관리자 앱 배포 후 **기본 추천 PG**에서 활성 PG를 한 곳 이상 선택하고 우선순위·사유를 저장한다. 요율은 확인된 범위와 조건이 있을 때만 입력한다.
3. **표준 업종에서 선택**에서 카테고리별 쉬운 업종명과 예시를 살펴보거나 검색해 복수 선택·일괄 등록한다. 검색은 표시명·저장 이름·원래 MCC 이름·예시·동의어·MCC 코드를 대상으로 하며, 카테고리 밖 결과도 찾는다. 선택은 카테고리와 검색을 바꿔도 유지된다. 기존 코드나 이름이 있는 행은 선택에서 제외되고 서버 검증도 유지된다.
4. **등록된 업종**에서 같은 카테고리와 검색으로 업종을 찾아 이름·추천 기준을 수정한다. MCC 코드와 판본은 각 업종의 **분류 정보**를 펼쳐 확인한다. 탐색 동작과 메타데이터 동기화 절차는 [업종 탐색 메타데이터](INDUSTRY_NAVIGATION.md)를 따른다.
5. 구매사 앱의 대응 변경을 배포한다. 기본 후보는 업종별 후보가 없을 때 Gray(추가 검토)로 안내하며, 구매사가 한 PG를 직접 선택한다.

접수 불가(Black) 업종, 삭제된 업종, 비활성 PG, 이전에 상담한 PG는 기본 추천으로 우회하지 않는다. 기본 설정이 없거나 후보가 전부 소진되면 추천할 수 없으므로 관리자 설정을 보완한다. 업종의 **미설정**은 기본 추천을 사용하며 차단하려면 **Black**을 사용한다.

## 카탈로그 출처

`lib/mcc-catalog.ts`는 [Visa Merchant Data Standards Manual](https://usa.visa.com/content/dam/VCOM/download/merchants/visa-merchant-data-standards-manual.pdf)의 2026년 4월 MCC 중 상담용으로 선정한 29개 업종을 담는다. 한국어 이름은 제품 내 번역이다. 전체 MCC 목록·한국표준산업분류(KSIC)·실제 PG의 가맹점 코드 확정을 대신하지 않는다. 코드와 판본을 DB에 함께 보존한다. 목록 밖 업종은 기존 직접 등록을 이용한다.

## 검증

- 기본 추천 저장: 권한, 활성 PG 제한, 입력 검증, 순서와 감사 로그.
- 표준 업종 등록: 권한, 등록된 코드만 허용, 배치 전체 검증, 재실행 중복 방지, 기존 이름 보존.
- 선택 화면: 카테고리 탐색, 별칭·예시·저장 이름·MCC 검색, 기존 업종 비활성, 복수 선택 유지.
- 구매사 저장소에서 실제 추천·상담 제출과 추가 DDL을 검증한다.

운영 DB 설정·배포는 별도다. 기본 PG와 업종은 자동으로 등록하지 않는다.
